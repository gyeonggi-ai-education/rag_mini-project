# 평가 기준 통일 제안 (팀 공유용)

Rerank(B)와 Multi Query(C)를 같은 조건에서 비교하려고, 협업 계획서(`docs/PROJECT_PLAN.md`)를 기준으로 평가 규칙과 골든셋 초안을 정리했다.
**계획서 내용은 그대로 따랐고, 계획서에 비어 있던 부분만 제안으로 채웠다.** 아래 2절의 제안 항목만 같이 확인해 주면 된다.

- 상세 규칙: [`EVAL_PROTOCOL.md`](EVAL_PROTOCOL.md)
- 골든셋 초안: [`golden_set.json`](golden_set.json) (기본 10문항, 확장 시 15문항)

---

## 1. 계획서 그대로인 것 (확인만)

| 항목 | 내용 |
|---|---|
| 역할·경로 | A `ingestion/`, B `retrieval/dense.py`·`rerank.py`·`api/`·`generation/`, C `retrieval/multi_query.py`·`evaluation/` |
| 청크 필수 필드 | `chunk_id`, `document_id`, `document_version`, `article`, `content` |
| 검색 모드 | baseline / rerank / multi_query / combined |
| 실험값 | 후보 20, 최종 K=5, 확장 질의 최대 3 (제안값, 결과 보고 조정) |
| 검색 지표 | Hit@K, Recall@K, MRR, Rerank 전 후보 Recall |
| 답변 불가 문항 | 검색 지표 평균에서 제외, 따로 평가 |
| 샘플 결과 | 전체 문서 성능으로 보고하지 않음 |
| 골든셋 규모 | 답변 가능 8 + 불가 2 = 10문항부터, 시간이 있으면 15문항 |
| 평가 실행기 | C가 만들고, 지표 계산은 이 코드 하나만 사용 |

## 3. 답변 평가 제안

0/1 척도. 모든 항목은 **1점이 좋은 쪽**이다.

| 항목 | 1점 조건 | 적용 |
|---|---|---|
| 정답성 | 핵심 내용이 골든셋 `reference`와 일치 | 답변 가능 문항 |
| 관련성 | 질문에 직접 답함 | 전체 |
| 근거 충실성 | 주장이 제시한 출처 조문으로 뒷받침됨 | 답변 가능 문항 |
| Hallucination 여부 | 출처에 없는 내용·조문·수치를 지어내지 않음 (1 = 없음) | 전체 |
| 답변 불가 처리 | 근거 없는 질문에 "문서에서 확인되지 않는다"는 취지로 답하고 지어내지 않음 | 답변 불가 문항 |

- **LLM 1차 채점:** 정답 조문 원문, `reference`, 답변, 출처를 함께 주고 항목별 0/1과 근거 한 줄을 출력.
- **사람 확인:** `final` 문항은 전부, `tune` 문항은 일부를 원문과 대조. 불일치하면 사람 판정이 우선, 불일치율은 보고서에 기록.
- 채점 프롬프트 파일과 temperature 0을 고정하고, 채점 모델 ID를 결과에 기록. 가능하면 답변 생성 모델과 다른 모델을 사용.

## 4. 요청 사항

**A (데이터·청킹)**
- 청크 `article` 값을 `제N조` / `제N조의M` 형식으로 만들어 줄 것 (제안 #2)
- 이 PDF 첫 페이지 표기: `[시행 2026. 7. 21.] [법률 제21311호, 2026. 1. 20., 일부개정]`. `document_version` 확인에 참고
- 내가 PyMuPDF로 확인한 범위에서는 **부칙이 없는 것으로 보임** (15페이지에서 "부칙" 0회, 제43조로 끝남). Docling 결과로 재확인 필요
- 샘플 청크에 골든셋 정답 조문(`golden_set.json`의 `gold_articles`)이 들어가면 샘플로도 평가 가능

**C (Multi Query·평가)**
- 제안 #3~#8과 3절의 채점 방식 확인, 평가 실행기에 반영
- 지표 계산 세부 규칙(중복 제거, MRR 0)이 다르면 지금 말해 줄 것

**전원**
- 골든셋의 정답 조문·항을 **원문과 대조해 확정** (현재 초안이며 작성자가 원문을 읽고 만들었지만 사람 확인 전)

## 5. 아직 비어 있는 것

- MonoRouter 지원 여부: 채팅, **임베딩**, **Rerank** (임베딩 모델·차원은 확인 후 결정. 잠정 후보 `text-embedding-3-small`, 1536)
- 답변 생성 모델·프롬프트, LLM 채점 모델
